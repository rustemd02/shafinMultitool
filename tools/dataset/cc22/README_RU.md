# CameraCoach — HTML-аудит качества v22

Это автономный HTML-инструмент, не новый датасет. Он показывает **реальные кадры уже собранного корпуса**, когда они предоставлены владельцем. Никогда не создаёт поддельные изображения и не выдаёт синтетические метки за независимую человеческую оценку.

## В комплекте

- **CameraCoach_Quality_Audit.html** — один автономный HTML, без внешних библиотек, аккаунтов, сетевых запросов и отправки данных.
- **build_embedded_audit.py** — приватная сборка HTML с 180 реальными случаями, изображениями и проверенными SHA-256; выходной файл не публиковать.
- **restore_dataset.py** — восстановитель зашифрованного выпуска v22.
- **README_RU.md** — текущая инструкция.

## A. Подключить восстановленный корпус в браузере

1. В приватной облачной среде восстанови четыре файла CC21_UNIFIED_000.zip — CC21_UNIFIED_003.zip из закрытой папки https://drive.google.com/drive/folders/1C2pPsbtu-xecYX0_rWM55lv0xf_YSRWU. Не загружай ключ в GitHub/Actions/публичный чат.
2. Используй команду:

    python restore_dataset.py --parts-dir /private/parts --key /private/PRIVATE_transport_key_DO_NOT_PUBLISH.pem --out /private/restored --all

3. Ожидается папка /private/restored/cc21-unified-actions, содержащая records.jsonl, verifier_sequences.jsonl, media/.
4. Открой CameraCoach_Quality_Audit.html и выбери **восстановленную папку** с данными. Работа идёт локально в браузере, без сетевых запросов.

Если не хочешь скачивать весь корпус на Mac, используй вариант B.

## B. Готовый HTML со встроенными кадрами (cloud-first)

Выполни после восстановления в личной облачной среде (например, в приватном Colab после самостоятельного подключения Google Drive):

    python -m pip install Pillow==11.3.0
    python build_embedded_audit.py --dataset /private/restored/cc21-unified-actions --template CameraCoach_Quality_Audit.html --out /private/CameraCoach_Audit_180.html --count 180

Скрипт проверит реальные SHA-256 изображений, выберет 180 разных групп происхождения, добавит до 30 дополнительных контрастных задач **без увеличения числа независимых сцен**, встроит оптимизированные JPEG исходных и конечных кадров. Выходной HTML можно открыть прямо в браузере — импорт папки не понадобится.

ВАЖНО: получившийся HTML содержит исходные изображения CameraCoach и должен храниться только приватно, например в закрытой папке Drive. Не публикуй его как GitHub artifact или GitHub Pages.

## Функции

- Три прошлых кадра и отмеченный субъект; корректные значения замысла/цели;
- 31 кандидат v19 или 11 кандидатов v20; решения keep / recommend / ask / abstain;
- Применимость действий, доступность и достижение измеримой синтетической цели;
- Конечные кадры для v20 при наличии в исходном verifier_sequences.jsonl; **для компактного v19 они недоступны и не имитируются**;
- Кривая видимости v20 в пяти точках;
- Слепой режим, сравнение задач одного кадра, фильтры источника, split, решения, оценки;
- Ручная оценка «верно» / «сомнительно» / «ошибка» / «пропуск» с отмеченными причинами;
- Экспорт JSON и CSV. Поскольку localStorage может быть удалён браузером, всегда выгружай итоговые оценки.

Управление: J/K или стрелки — переход между случаями; 1–4 — оценка; B — слепой режим.

## Что НЕ считается доказанным

Техническая целостность 4 889 записей и разбиение групп доказаны отдельно. Этот HTML помогает исследовать качество 180 выбранных задач, но не превращает синтетическое измерение в художественную оценку, не доказывает перенос на реальные iPhone-съёмки и не создаёт независимых human-utility меток. Нельзя автоматически переносить отметки одного проверяющего в human-gold или делать CAMERACOACH_TRAINING_READY=true на основании одной HTML-галереи.

Код HTML и сборщика не содержит приватных ключей, оригинальных медиа или обучающих меток. Реальные изображения попадают только в приватно собранную версию HTML.
