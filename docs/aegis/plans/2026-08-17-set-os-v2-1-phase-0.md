## Architecture

SET OS реализуется снизу вверх:

1. Policy v2.3 остаётся authority визуальных решений; O-5/O-6 не меняют behavior
   ownership и перечень superseded clauses, но заменяет визуальную грамматику
   v2.1.
2. `UI/DesignSystem/` владеет только повторяемыми visual primitives, typography, motion/haptic presets, localization keys и reusable components.
3. Deterministic fixture catalog владеет preview payloads, но не создаёт вторую product state machine.
4. DEBUG-only gallery root отображает production DesignSystem components на fixtures и не меняет CommercialShell routes.
5. Production entry/live/generator/library views остаются без SET OS-интеграции до явного owner approval.
