## M10-013 — software keyboard (verify-and-close)

`SceneInputSheet` owns keyboard interaction through `@FocusState`
focus ownership, `safeAreaInset(edge: .bottom)` for the primary
action (never a guessed keyboard height, no second modal layer), and
`.scrollDismissesKeyboard(.interactively)` for explicit interactive
dismissal; the editor keeps the command visible while focus scrolls
the text into view. Draft preservation across dismissal/reopen is
pinned by the UI test
`testScreenplayDraftSurvivesCancelReopenAndKeyboardRecomposition`,
and the M10-009 iPad input-sheet batch (3/3) covered the regular-width
layout with keyboard-safe actions. Storyboard editor and marker-name
sheet use the same sheet-with-safe-area pattern (M8 chain).
